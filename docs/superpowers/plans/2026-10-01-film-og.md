# Film + Share Cards + Cafénista Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** This plan delivers three things:
- The Cafénista sting is fixed (times, minimum text size).
- A 40-second film of the work plays in a sheet opened from the hero tour pill, in 16:9 and 1:1, EN and TH.
- The share cards are rebuilt in the frame.md look.

**Architecture:** The plan has four layers:
- Video sources live in `design/clips/` as HyperFrames 0.8.97 compositions, with build scripts that write committed outputs to `public/`.
- On the site, a code-side registry `src/lib/film.ts` feeds a new client island `FilmSheet` (a native `<dialog>`, hash `#film`). It opens from a delegated `a[data-film]` click, the same contract as `ProjectSheet`'s `a[data-sheet]`.
- The entry is an `<a>` inside the existing tour pill, so it works without JS as a plain link to the file.
- Share cards are static PNGs rendered from `design/og/`.

**Tech Stack:** HyperFrames 0.8.97 (`npx hyperframes@0.8.97`), GSAP, ffmpeg 8 (x264, libvpx-vp9, AAC, Opus), Python 3 + Pillow/NumPy for checks, Next.js 15 / React 19, plain CSS in `@layer components`, Vitest + Testing Library, Playwright via `scripts/qa-lib.mjs` `loadChromium()`.

**Spec:** `docs/superpowers/specs/2026-10-01-film-og-design.md` (read it; §3.1 is the only copy allowed on screen). Brand truth: `design/clips/frame.md`.
