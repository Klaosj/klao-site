# White Edition — Polish amendments (A01–A10)

Approved by Klao 2026-09-26 ("ตาม recommendation ทุกข้อ") after the Polish Lab review.
Reference implementation (working demos, exact CSS/JS): `design/white-edition/polish-lab/index.html`
(published copy: Klao's private artifact "Daylight Polish Lab"). Research behind it: live captures of 16
reference sites and motion/icon sources, all checked 26 Sep 2026 (sources listed at the bottom of the lab page).

These amendments extend the phase plans. Each row names the task that absorbs it; the controller carries
the row into that task's dispatch. Where a row and a phase plan disagree, the row wins (master R27).
Global constraints still apply: no new dependencies, only transform/opacity animate (two tiny icon
exceptions below are named), reduced motion never hides content, Kram is the only accent, GoNai green only on GoNai.
