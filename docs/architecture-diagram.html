klao-site · system overview

Notion is the source of truth. The site never waits on it.

Next.js 15 App Router, React 19 Server Components. Every content read passes through lib/content.ts, which decides between live Notion, the last good ISR build, and committed fixtures — so an outage upstream degrades quietly instead of taking the site down.

The decision node

Three ways out of a Notion failure

  • No NOTION_TOKEN → fixtures, no network call at all
  • Fails during ISR revalidate → rethrow, so the last good build keeps serving
  • Fails during the production build → fixtures, because there is no cache to fall back to

Source of truth

Six Notion databases

  • PROJECTS · POSTS · CAREER
  • PROFILE · SKILLS · QUESTIONS
  • Rows map to typed models in lib/models.ts
  • Signed image URLs expire, so they go through the proxy route

Edges

Bilingual by redirect

  • Middleware prefixes any unprefixed path with /en
  • Skips api/, _next/, and anything with a file extension
  • robots.ts and sitemap.ts share the 3600s window
